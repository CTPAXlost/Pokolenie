# Источники подписок (whitelist)

По умолчанию в приложение зашиты несколько raw-лент GitHub:

| Имя | URL |
|---|---|
| Whitelist VLESS (rjsxrd) | https://raw.githubusercontent.com/whoahaow/rjsxrd/refs/heads/main/githubmirror/split-by-protocols/vless.txt |
| Whitelist Trojan (rjsxrd) | https://raw.githubusercontent.com/whoahaow/rjsxrd/refs/heads/main/githubmirror/split-by-protocols/trojan.txt |
| deqwl VLESS | https://raw.githubusercontent.com/dequar/deqwl/refs/heads/main/deray.txt |
| sbornik VLESS | https://raw.githubusercontent.com/kort0881/sbornik-vless/main/configs/final/vless.txt |
| sbornik Trojan | https://raw.githubusercontent.com/kort0881/sbornik-vless/main/configs/final/trojan.txt |

Любой источник можно выключить или добавить свой URL на экране **Источники**.

После обновления при включённом авто-пинге неотвечающие узлы удаляются.
